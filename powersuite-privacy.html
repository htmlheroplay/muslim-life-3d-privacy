Commitment to Privacy

The HTML Hero – WebDev & Web3 PowerSuite (Extension ID: ochjcijebcapbofdfjidadfmpgfihmdg), developed by The HTML Hero ("we", "us", or "our"), is designed around a privacy-first, local-first architecture.

The extension helps developers inspect and analyze webpages directly in the browser. Information inspected by the extension is processed locally for the requested feature and is not intentionally collected as a user profile, sold, or used for advertising.

!Some features may communicate with third-party public services, such as cryptocurrency price APIs. Those network requests are described below and are separate from the extension's local inspection features.

The extension does not operate a backend account system or intentionally collect personal information for its own databases. The following describes how information is handled by the extension's features.

Permissions Justification

The extension requests permissions that support its developer utility features. Each permission is used for the purpose described below.

activeTab

Allows the extension to interact with the currently active tab when the user invokes supported extension features, such as webpage inspection or an on-page SEO audit.

scripting

Used to inject temporary inspection logic required to read supported webpage information such as title, description, OpenGraph data, canonical information, and heading counts.

storage

Used through chrome.storage.local for supported local extension preferences. These preferences are stored by Chrome on the user's device rather than in an extension-owned remote database.

Host Permission (<all_urls>)

If enabled by the extension manifest, this permission allows the extension's developer tools to operate across websites where the user chooses to use its inspection features. It is required for webpage inspection functionality intended to work on arbitrary websites.

No Remote Code (Manifest V3)

The extension is designed to comply with Chrome's Manifest V3 restrictions regarding executable remote code.

  • Bundled extension code: The extension's application logic is packaged with the extension rather than downloaded as executable JavaScript at runtime.
  • No dynamic execution: The extension does not intentionally use eval() or equivalent dynamic code execution for its normal operation.
  • Public API requests: The Crypto Ticker feature may request publicly available cryptocurrency price information from the configured market-data service, such as the Binance public API. These requests are used to display market prices and are not intended to transmit a user account, password, or extension profile.

Third-Party Services

Certain extension features may communicate with external services to retrieve information requested by the user.

Cryptocurrency Price Data

The Crypto Ticker feature may use a public cryptocurrency market-data endpoint to retrieve current prices for supported assets such as SOL and TON.

Because these are external network requests, the service receiving a request may process normal technical network information associated with the request, such as an IP address. The HTML Hero does not use these requests to create its own personal profile of the user.

Users should review the privacy practices of the relevant third-party service for information about how that service handles network requests.

Data Retention & Security

The extension does not maintain an extension-owned remote database of user browsing activity or inspection results.

Temporary webpage inspection results are processed in the browser while the relevant feature is being used. Supported local preferences may remain in chrome.storage.local until they are changed, cleared, or removed with the extension.

Uninstalling or removing the extension generally removes its local extension storage managed by Chrome.

User Control

You can stop the extension from accessing webpage content at any time by disabling or uninstalling the extension from Chrome.

You can also clear Chrome extension data through Chrome's settings where applicable.
